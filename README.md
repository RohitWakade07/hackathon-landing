HackNova 2025 - Landing Page

How to run locally:
1. Ensure Node.js is installed (v14+ recommended).
2. Open terminal in this project folder.
3. Install dependencies:
   npm install
4. Start the server:
   node server.js
5. Open http://localhost:3000 in your browser.

Files:
- index.html
- style.css
- script.js
- server.js
- package.json

The server will create data.xlsx in the project folder when the first registration is submitted.
