Track 1: Next-Gen Agri AI & Data Science

AI-Driven Leaf Health Assessment, Damage Quantification, and Leaf Area Index Calculation

Description: Develop a lightweight AI system that analyses crop leaf images to identify multiple possible diseases and pest damages using pre-trained deep learning models. The system should also estimate the percentage of leaf area affected by each detected condition using segmentation techniques, along with calculating the Leaf Area Index (LAI) to provide an additional quantitative measure of plant canopy condition.
Expected Outcomes:
  • Upload a leaf image from any crop.
  • Receive a report listing all detected diseases/pest damages (multi-label classification).
  • View the scale of damage for each detected condition, represented both as a descriptive category (e.g., low, moderate, severe) and as an approximate percentage of leaf area affected.
  • Calculate the Leaf Area Index (LAI) from the uploaded image.
  • See an overlaid segmentation mask highlighting the affected regions.
Recommended Datasets:
  • PlantDoc Dataset (GitHub): 2,598 images, 13 plant species, 30 classes. Designed for Indian conditions.
  • PlantVillage Dataset (Kaggle): 54,000+ images, 14 crop species, 26 diseases. Clean backgrounds, ideal for segmentation.
  • CCMT Dataset (Mendeley Data): 100,000+ images, 22 disease classes, 4 major crops. Great for robust model training.

AI-Assisted Flag Leaf Measurement and Yield Prediction

Description: Develop a machine learning pipeline that processes UAV imagery of crop fields to detect and measure the morphological dimensions of the flag leaf. Using these measurements, the system should apply a regression model to predict the final grain yield for the corresponding crop.
Expected Outcomes:
  • Upload a UAV image of a crop field.
  • Automatically detect flag leaves in the image using a pre-trained model.
  • Measure the length, width, and area of each detected flag leaf (converted from pixels to centimeters using UAV image metadata).
  • Predict the final grain yield for the crop using a regression model trained on provided data.
  • Display visual overlays showing detected leaves and measurement annotations.
Recommended Datasets:
  • Global Wheat Head Dataset (GWHD) (Kaggle): 190,000+ labeled wheat heads, diverse conditions. Premier for object detection.
  • Plant Phenotyping Datasets (Platform): UAV imagery, trait measurements, various crops. Explore for leaf/yield data.

AI-Powered Automated Quantification of Symbiotic Root Nodules

Description: Develop a computer vision application that analyses an image of an excavated legume root system to automatically detect, count, and measure symbiotic root nodules. This will replace the labour-intensive manual process currently used in soil health research.
Expected Outcomes:
  • Upload an image of an excavated legume root system.
  • Automatically detect and count all visible root nodules using a pre-trained detection/segmentation model.
  • Measure the size distribution of detected nodules (in mm or cm, using scale reference in the image).
  • Generate a Nodulation Score based on total nodule count and size distribution.
  • Display visual overlays marking detected nodules and their measurements.
Recommended Datasets:
  • Minirhizotron Images of Soybean Roots and Nodules (Dryad): 2,700+ images, controlled environment, automated analysis pipelines.
  • Legume Root Nodule Image Dataset (Mendeley Data): 1,000 images, various legumes, nodule counting/classification.
  • Global Root Image Dataset (GRID) (Zenodo): 25,000+ images, 125 plant species, root segmentation/measurement.
  • UNL Plant Phenotyping Datasets (UNL): Maize/sorghum root phenotyping, transferable techniques.

High-Throughput Seed Damage and Pest Infestation Analysis

Description: Build an AI-driven imaging system capable of batch-processing seed samples to automatically detect and quantify various forms of damage, such as cracks, discoloration, mold, and pest-related defects (including counting insect eggs or holes on individual seeds).
Expected Outcomes:
  • Upload multiple seed images at once.
  • Damage classification for each seed (e.g., healthy, cracked, discolored, mold-infected).
  • Pest infestation indicators, including egg/larvae count or visible holes.
  • Damage Severity Scale for each seed (e.g., 0–No Damage, 1–Mild, 2–Moderate, 3–Severe) based on the percentage of seed surface affected.
  • Quantitative summary for the entire batch: percentage of damaged seeds per category, average pest count per seed, size distribution of damage.
  • Exportable data table and summary charts for further research or quality control.
Recommended Datasets:
  • Damaged vs. Healthy Seeds Dataset (Kaggle): 3,600+ images, binary classification.
  • Seed Image Dataset (Kaggle): 4,500+ images, 14 plant species, seed classification.
  • Global Wheat Head Dataset (Kaggle): High-res images, feature detection (discoloration, mold, etc.).
  • Insect Pest Image Dataset (Kaggle): Thousands of images, pest/egg detection for seed health.

AgriCurate: AI-Powered Dataset Quality and Curation Tool

Description: Build an AI-assisted data curation platform that can process agricultural datasets (images, sensor data, or hybrid datasets) in bulk to automatically evaluate and enhance dataset quality.
Expected Outcomes:
  • Upload complete datasets or batch files.
  • Curation Metrics for Each Dataset: completeness, timeliness, precision, provenance, plausibility.
  • Data Quality Scorecard: a single score summarizing overall dataset health.
  • Anomaly Detection Report: highlights of mislabeled data, extreme outliers, or duplicates.
  • Batch Summary: percentage of entries failing quality checks, distribution of errors across categories, recommendations for corrective actions.
  • Exportable Outputs: PDF report with visual charts, detailed data tables, and issue tracking logs for future audits.
Recommended Datasets:
  • PlantDoc Dataset (GitHub)
  • PlantVillage Dataset (Kaggle)
  • CCMT Dataset (Mendeley Data)
  • Global Wheat Head Dataset (Kaggle)
  • Plant Phenotyping Datasets (Platform)
  • Minirhizotron Images of Soybean Roots and Nodules (Dryad)
  • Legume Root Nodule Image Dataset (Mendeley Data)
  • Global Root Image Dataset (GRID) (Zenodo)
  • UNL Plant Phenotyping Datasets (UNL)
  • Damaged vs. Healthy Seeds Dataset (Kaggle)
  • Seed Image Dataset (Kaggle)
  • Insect Pest Image Dataset (Kaggle)
